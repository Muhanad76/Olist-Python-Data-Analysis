Olist E-commerce Data Analysis Using Python

Project Overview (نبذة عن المشروع)

This project analyzes the Olist e-commerce dataset using Python, Pandas, and Matplotlib to explore sales performance, order trends, product categories, and customer locations.

Tools & Technologies (الأدوات والتقنيات)

* Python
* Pandas
* Matplotlib

Key Analysis (أبرز التحليلات)

* Order status and delivery performance
* Payment methods and payment analysis
* Monthly order and sales trends
* Top 10 product categories by sales
* Top 10 states by sales
